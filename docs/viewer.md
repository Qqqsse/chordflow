# 看譜器（M4）

位置：`apps/web/src/components/viewer/`。整份看譜器只靠和弦譜文件與 `@chordflow/music-theory` 在瀏覽器端運算，
不需要資料庫、worker 或 GPU。

## 元件

| 檔案                  | 用途                                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------------------- |
| `chart-viewer.tsx`    | Client component：持有 ViewerState、計算 `transposeChartDisplay`、處理快捷鍵                                  |
| `viewer-controls.tsx` | 移調、移調夾、記譜（和弦／羅馬級數／Nashville）、字級；「進階設定」內有移調夾模式、顯示按法或實際音、全部重設 |
| `chord-sheet.tsx`     | 依段落、行渲染譜面                                                                                            |
| `chord-label.tsx`     | 單一和弦；級數模式的 suffix 以上標呈現；無法解析的和弦原樣顯示並加虛線底線與說明                              |
| `line-layout.ts`      | 純函式：把一行拆成可渲染單位（有單元測試）                                                                    |
| `viewer-state.ts`     | ViewerState reducer（有單元測試）                                                                             |

## 排版模型

- 每個和弦與它所對應的歌詞段落組成一個 **inline-block**：和弦在上、歌詞在下，寬度取兩者較大者。
  和弦名稱比歌詞段寬時，後面的段落會被推開，不會重疊。
- inline-block 的 baseline 是最後一行文字，所以有和弦與沒有和弦的歌詞會在同一條基線上。
- 區塊 `max-width: 100%`，過長的段落會在區塊內換行，不會造成水平捲動。
- 和弦落在英文單字中間時（`swe[C]et`），只把那個單字的片段黏在一起（不換行），其餘文字照常換行。
  中文字之間不黏合，可在任何字之間換行。
- 只有和弦的行（間奏）以一列和弦呈現；空行保留為間距。
- 不使用空白字元或等寬字型對齊。和弦標籤設為 `user-select: none`，複製時只會複製歌詞。

## ViewerState 與不變條件

移調、移調夾、記譜方式、顯示目標、字級都只存在 ViewerState，**不會**修改和弦譜或 RecordingSync。
移調範圍 −11…+11；UI 移調夾 0–7（理論層支援 0–12）。移調夾模式必須明確選擇：

- **保持音高**：聲音不變，按法跟著移調夾改變（預設）。
- **保持按法**：按法不變，聲音跟著移調夾改變。

調性未知時級數按鈕停用，並顯示說明文字。登入的讀者在曲庫譜頁（`/charts/[id]`）的 ViewerState 會儲存為
UserChartPreference v1（`viewer-preferences.ts`），下次開啟時還原；demo 頁與未登入時不保存。

## 快捷鍵

`+`／`=` 升半音、`-` 降半音、`0` 回原調。焦點在輸入欄位或下拉選單時不作用；按住 Ctrl／⌘／Alt 時也不作用。

## 測試

- 單元測試：`line-layout.test.ts`、`viewer-state.test.ts`。
- Playwright（`apps/web/e2e/viewer.spec.ts`）：移調斜線和弦、移調夾、切換實際音／級數、重設與重新載入後原譜不變、
  保持按法模式、快捷鍵、鍵盤操作、字級。
- **排版幾何測試**：320px 直向（中文、英文、〈送別〉）、手機、平板橫向、桌機與深色模式，各自在預設字級、
  最大字級與羅馬級數下檢查：頁面沒有水平溢出、任兩個和弦標籤不重疊、每個和弦都在它的歌詞起點正上方
  （誤差 ≤ 1px）且沒有被裁切、同一視覺列的歌詞共用基線。每個案例的截圖會附在測試報告中。

### ADR-001（已接受，擁有者 2026-10-24 確認）：以幾何驗證取代像素比對的視覺回歸

SPEC §8 要求「visual regression」。像素截圖比對會受字型版本、抗鋸齒與作業系統影響，在雲端沙盒與 GitHub Actions
之間容易誤報，而且不會說明「哪裡錯了」。本專案改以上述幾何斷言驗證 SPEC 真正關心的性質（對齊、不重疊、不溢出、
基線一致），並把截圖附在報告中供人工檢視。若日後改用固定版本的 Playwright Docker 映像執行 CI，可再加上
`toHaveScreenshot` 基準圖。
