# 指法、播放模式與離線（M5）

## 吉他指法（`packages/guitar-voicings`）

- **指法與和弦名稱分開**：指法是六條弦的格數（低音 E 弦到高音 E 弦，`-1` 不彈、`0` 空弦），加上手指、barre 與標籤。
  id 由格數決定，例如 `v_x32010`（每弦一個 base-36 字元，`x` 為不彈），所以 10 格以上也不會混淆。
- **驗證**（`validateVoicing(voicing, chord, tuning)`）：必要和弦音都要響、不能有和弦外音、最低音必須是斜線低音
  （沒有斜線時必須是根音），再加上可彈性檢查（跨格 ≤ 5、手指 ≤ 4、barre 合理、空弦或不彈的弦不能有手指）。
  可省略的音（自然五度、11／13 和弦下的 9 度）缺少時仍視為有效。
- **指法庫**：精選開放和弦與斜線和弦，每一筆都在測試中對它所寫的和弦驗證過；另以 E 型、A 型封閉和弦樣板
  在 1–12 格展開，只保留驗證通過的。沒有已驗證指法的和弦（例如 `B7/D#`、`C13b9`）回傳明確的
  `unsupported`，看譜器顯示「沒有已驗證的指法」，不會捏造。
- **非標準調弦**：用同一套驗證；沒有指法通過時回傳 unsupported，不假設標準調弦的按法可用。
- **推薦排序**（可設定權重，結果固定）：barre、跨格、把位、中間不彈的弦、手指數、高於偏好難度的懲罰、
  與前一個和弦的位置差。和聲正確是硬性條件。
- **選擇順序**：使用者自己的選擇 → 譜上單一位置的覆寫 → 編曲的和弦預設 → 推薦第一名。
  引用的 id 若無法構成該和弦，會被略過並回報（`ignored`），不會被強制使用。
- **指法圖**：`diagramGeometry` 產生純幾何資料（弦、格、上枕或「5fr」標示、空弦／不彈標記、手指圓點、barre），
  React 以一般 SVG 元素繪製；不存 SVG 檔、不注入 HTML。

看譜器的指法圖區塊列出**實際要按的和弦**（會跟著移調與移調夾改變）。編曲的預設指法是寫給原調和弦的，
只在沒有移調、沒有夾 capo 時套用。使用者的選擇只存在 ViewerState，不會改動原譜。

## 播放模式

- **連續捲動**：可調速度（每秒 5–120 像素），按鈕或 `P` 開始／暫停。偵測到滾輪、觸控或導覽鍵（方向鍵、Page
  Up/Down、Home/End、空白鍵）就立即停止，不與使用者搶捲動。
- **減少動態**：系統設定 `prefers-reduced-motion: reduce` 時，自動捲動改成每隔一段時間跳約 80% 螢幕高度，
  不做連續動畫。
- **分頁模式**：譜面排進固定高度的欄（平板／桌機 2 欄、手機 1 欄），由左到右閱讀；用按鈕或 ←／→、Page
  Up/Down 一次翻一整頁。不會出現「兩欄並排卻要上下捲」的混亂順序。歌詞行與段落標題不會被拆到兩欄。

## 離線（PWA）

- **明確儲存**：在譜頁按「儲存離線」才會把和弦譜存進這個裝置的 IndexedDB（資料庫 `chordflow-offline`）。
  再按一次會更新；若線上版本已更新，會顯示「不是最新版本」。
- **離線譜庫** `/offline`：顯示份數、每份的儲存時間與格式版本，可移除單份、兩段式確認的「全部清除」、重新整理。
- **離線開啟** `/offline/view?id=…`：完全在瀏覽器端運算（移調、移調夾、級數、指法圖）。
- **讀取時一律重新驗證**：紀錄版本不符、和弦譜驗證失敗或儲存位置不一致時，**不會**顯示損毀的譜，
  而是顯示原因與「移除」按鈕，並提示連線後回原譜重新儲存。
- **Service worker**（`apps/web/public/sw.js`）：安裝時預先快取 `/offline`、`/offline/view` 與它們引用的
  `/_next/static` 資源；靜態資源 cache-first；這兩個頁面 network-first、離線時用快取；其他頁面離線時顯示
  「目前離線」說明頁。**從不快取 `/api/*`**。要讓所有快取失效時，調高 `sw.js` 的 `VERSION`。
  只在 production build 註冊。
- **帳號隔離**：目前沒有帳號，所有紀錄放在 `guest` 命名空間。M6 加入帳號後改用使用者 id 作為命名空間，
  並在登出時清除該帳號的私人離線資料，避免在共用瀏覽器上外洩。
- 不提供任何受版權保護音訊的離線下載。
