# 測試資料（fixtures）來源與權利

本目錄只放兩種內容：

1. **虛構內容**：為本 repo 自行創作的歌名、歌詞與和弦（檔名 `demo-*`）。
2. **公有領域（public domain）歌曲**：歌詞與曲調皆已超過著作權保護期間；和弦編配由本專案自行撰寫（檔名 `pd-*`）。

不得加入任何仍受保護的歌詞、和弦譜或音訊。新增公有領域歌曲時，請在下表記錄作者與卒年，
並確認在台灣（著作人終身加 50 年）與終身加 70 年的地區都已屬公有領域。

| 檔案                                 | 歌曲          | 詞                             | 曲                                                                 | 和弦編配       |
| ------------------------------------ | ------------- | ------------------------------ | ------------------------------------------------------------------ | -------------- |
